# Free Money Finder

A one-page checklist of legitimate places to find money you're owed (unclaimed property, lost tax refunds, savings bonds, old 401(k)s, class action settlements, and more). Every item links to an official source, and a tracker in the page saves your progress in your browser.

## Hosting (free)

The page is hosted on GitHub Pages with the workflow in `.github/workflows/pages.yml`.

One-time setup: in the repo, go to **Settings → Pages → Build and deployment → Source** and pick **GitHub Actions**. Then re-run the workflow from the **Actions** tab. The site will be at `https://<your-username>.github.io/money/`.
